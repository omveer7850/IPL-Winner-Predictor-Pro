# IPL Winner Predictor Pro

Machine Learning based IPL Match Winner Predictor.

## Features
- IPL Winner Prediction
- Team Selection
- Toss Winner Selection
- Toss Decision
- Venue Selection
- Season Selection
- Confidence Score

## Tech Stack
- Python
- Pandas
- Scikit-Learn
- Streamlit

## Run Project

pip install -r requirements.txt

streamlit run app.py
